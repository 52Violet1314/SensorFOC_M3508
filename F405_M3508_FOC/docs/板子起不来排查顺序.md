# 板子起不来 → 电机不转:排查顺序(按这个顺序做,别跳)

> 现在卡在**第一层:板子根本没在跑**。
> 证据: ST-Link 报 `Voltage: 0.66V`(目标板 VDD 实测),板子 USB CDC 不枚举,
> 三个调试工具都读不到芯片。芯片没电 → 固件没跑 → **没有任何 PWM 输出 → 电机不可能转**。
> 所以现在无论怎么改电机参数都是白费,先让板子活过来。

---

## 第 0 层:判断"固件到底有没有在跑"(不用探针,10 秒)

> ### ⚠️ 先看这条:2026-10 踩过的坑 —— printf 参数不匹配会让串口**一行都不打印**
>
> 固件里 `printf` 的**格式符个数和实参个数不匹配, 编译器默认不报错**(除非开 `-Wformat`),
> 但运行时会从栈上读垃圾 → `vsnprintf` 崩溃 → **主循环 HardFault 卡死 → 串口完全没输出**。
> 现场表现和"板子坏了"一模一样, 很容易误判。
>
> **本工程已经加了防护**: 编译时带 `-Wformat=2`(仓库 `tools/build.ps1`),
> 另有一个静态检查脚本, 改完代码跑一下:
> ```powershell
> python tools/audit_printf.py     # 检查全工程 printf 的格式串与实参个数
> ```
> 现在是 `16 个 printf 调用, 0 处不匹配`。**加打印调试的时候务必跑一次。**

| 现象 | 说明 |
|------|------|
| **绿灯(PB0)以约 1Hz 闪烁** | 固件在跑 → 跳到第 3 层 |
| 绿灯常亮 / 常灭 | 芯片没跑。**PB0 上电默认是低电平**,"亮"可能只是默认电平,不代表活着 |
| 板子 USB 插上电脑后出现新的 `USB 串行设备 (COMxx)` | 固件在跑(本工程是 USB CDC) |
| 没有新 COM 口 | 芯片没跑 → 第 1 层 |

```powershell
# 看板子 CDC 有没有枚举
Get-PnpDevice -PresentOnly -Class Ports | Select-Object FriendlyName, InstanceId
```

## 第 1 层:电源(现在的问题就在这)

| 测哪里 | 期望 | 不对怎么办 |
|--------|------|-----------|
| MCU 的 **VDD–VSS** 引脚 | 稳定 **3.3V** | 就是现在的问题,继续往下 |
| **3.3V 稳压器输出** / 板上 3V3 测试点 | 3.3V | 查稳压器输入、使能脚、焊接 |
| 稳压器**输入端**(5V 或 12V) | 5V / 12V | 从电源源头一级级往板子量 |
| **断电**量 3V3–GND 电阻 | 几百 Ω ~ 几 kΩ | 只有几 Ω/0 Ω = **短路**,摸哪个元件发烫 |

**最容易搞错的一点:** 你给功率级供 12V 母線,**不等于 MCU 有电** ——
MCU 的 3.3V 通常是另一路:板载 LDO 从 12V/5V 降下来,或者由 USB 5V 供。
**12V 有电 ≠ 3.3V 有电。**

先把板子自己的 USB 插上(多数板 USB 5V → LDO → 3V3),量 MCU VDD 是否 3.3V。

## 第 2 层:调试口(SWD)

3.3V 正常之后再查这个,顺序别反:

```powershell
pwsh -File tools/swd_test.ps1              # CMSIS-DAP / MCU-Link
pwsh -File tools/swd_test.ps1 -Interface jlink
```

判读:

| 输出 | 含义 |
|------|------|
| `Info : SWD DPIDR 0x2ba01477` + `Cortex-M4 r0p1 detected` | 通了 |
| `Error connecting DP: cannot read IDR` | 芯片不应答:供电 / 共地 / 接线 / RDP |
| `Voltage: 0.7V` 之类(STM32CubeProgrammer) | **目标板 VDD 不对**,回到第 1 层 |

接线要求:
```
SWDIO → PA13     SWCLK → PA14     GND → 板子 GND(必须!)
VTref/3V3 → 板子 3V3(探针靠它判断电平)    可选 NRST → NRST
```

## 第 3 层:固件在跑,再谈电机

只有第 0 层通过(绿灯闪、有 COM 口)之后,才轮到电机。
**但先看中断预算那一行** —— 如果 `cyc ≥ 25us`,电机是不可能转的:

```
# ctrl_step_max=5321 cyc = 31.67 us (budget 25.00 us @ 40000 Hz)   ← 超了, 先解决这个
# prof(2s内峰值): total=31.67us | smo=?.??us vf=?.??us | 其余=?.??us
```

命令序列:

```
stat                  # 看 TIM1 自检行: CR1=0x0081 CCER=0x1111 才对
prot 0                # 先关失步保护, 排除"保护在捣乱"
vf 300                # 进开环 (此时会先对齐 300ms)
```

然后盯**每 500ms 自动打印的那行**:

```
# OL t=12345 v_out=2.80V I=14.2A |E|=0.05V rpm_cmd=180 rpm_obs=0 vdc=12.1
     aligned no-emf boost_lo | vlo=2.80 fres=6.0 fstart=2.0 prot=1
```

| 看到什么 | 说明 | 怎么办 |
|----------|------|--------|
| `v_out≈0` 且 `I≈0` | 电压没给出去 | 查 `stat` 的 TIM1 自检、EN_Gate、母线电压 `vdc` |
| `I≈0` 但 `v_out` 正常 | 驱动没输出/相线没接/EN 没使能 | 量三相有没有 PWM;查 EN_Gate 引脚 |
| `I` 10~15A、`|E|` 还是 0、电机不转还发热 | 起动转矩不够或机械卡 | `vlo 4.0`、`fres 9`;断电手盘输出轴 |
| `|E|` 涨起来、`flags` bit1 清零 | 牵入成功 | 打开保护 `prot 1`,开始采数据 |

## 一句话总结

**现在的"电机不转"是结果,原因是板子没电**(`Voltage: 0.66V`)。
先把 3.3V 修好、让绿灯闪起来、让 USB 枚举出 COM 口,
再回头做第 3 层的电机测试 —— 顺序反了会一直在错误的地方找问题。
